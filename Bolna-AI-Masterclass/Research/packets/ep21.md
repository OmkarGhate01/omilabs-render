## Choosing providers (concepts/choosing-providers)

How to pick the right transcriber, LLM, and voice synthesizer for your Bolna agent based on language, latency, and quality requirements.

Every Bolna agent uses three provider categories: a **transcriber** (speech-to-text), an **LLM** (language model), and a **synthesizer** (text-to-speech), plus a **telephony provider** to carry the call. Read the provider guides first to see what each one offers, then use this page to pick a combination for your use case.

  Provider model lineups change frequently. The specific model names here are current examples — always check the relevant [LLM provider page](/docs/language-models) or the provider's own docs for the latest recommended model.

## Quick decision guide

| Primary concern | Transcriber | LLM | Synthesizer |
| - | - | - | - |
| English, lowest latency | Deepgram Nova-3 | `gpt-5.4-mini` | ElevenLabs Turbo v2.5 |
| Indian languages (Hindi, Tamil, etc.) | Sarvam | `gpt-5.4-mini` | Sarvam |
| European multilingual | Azure Speech | `gpt-5.4` | Azure TTS |
| Enterprise / data residency | Azure Speech | Azure OpenAI | Azure TTS |
| Cost-sensitive high volume | Deepgram Nova-2 | `deepseek-v4-flash` | AWS Polly |
| Complex reasoning or sensitive domain | Deepgram Nova-3 | `gpt-5.4` or `claude-sonnet-5` | ElevenLabs |

## Bolna voice AI integrations (integrations)

Integrate Bolna Voice AI with tools like Twilio, Plivo, OpenAI, ElevenLabs, Deepgram, and Zapier to enable seamless voice automation and workflows.

Every provider below is connected from one place in the dashboard: **Settings → Integrations**.
Use the **Telephony**, **LLM**, **TTS**, **STT** and **Tools** filters on that page to find a
provider, then click **Connect** on its card.

  Bolna doesn't charge for usage on providers you connect yourself — you pay that provider directly.
  See [Connect provider credentials](/docs/providers) for the step-by-step flow and the keys each provider needs, and [Choosing providers](/docs/concepts/choosing-providers) to pick a transcriber, LLM and voice for your use case.

## Connect your provider credentials (providers)

Connect your own telephony, LLM, speech-to-text, text-to-speech and tool accounts to Bolna from Settings → Integrations, and see the keys each provider needs.

  We don't charge for any usage for providers that you have connected to Bolna.<br />

  We store all your provider credentials securely using [Infisical](https://infisical.com/).

Every provider you can bring to Bolna — telephony, LLM, TTS, STT and tools — is connected from a
single place in the dashboard: **Settings → Integrations**.

### Steps to add your own provider credentials:

**Log in to the dashboard**:
    Log in at [platform.bolna.ai](https://platform.bolna.ai)

**Open Settings → Integrations**:
    Navigate to **Settings** from the left menu bar and open the [**Integrations**](https://platform.bolna.ai/providers) page

**Find your provider**:
    Filter by **Telephony**, **LLM**, **TTS**, **STT** or **Tools**, or type the provider's name into **Filter providers...**

**Connect it**:
    Click **Connect** on the provider's card and fill in the credentials it asks for

**Save your Provider**:
    Save the provider. Its card now shows as connected, and the provider becomes selectable on your agents

  Already-connected providers show their status on the same card, and each card is where you
  disconnect or update credentials later.

## Add a new provider API (api-reference/providers/add)

POST /providers
Learn how to securely add a new provider to your Bolna account by specifying the provider's name and associated credentials.

You can add your own providers securely in Bolna — the API equivalent of connecting one from **Settings → Integrations** in the dashboard. Please [read this page](/docs/providers) for more information about all current supported providers.

## List providers API (api-reference/providers/get)

GET /providers
Retrieve all providers associated with your Bolna account, including their IDs, names, and creation timestamps.

## Providers APIs overview (api-reference/providers/overview)

Add and manage your own providers securely in Bolna, supporting various telephony and voice services.

  You can add your own providers securely in Bolna. These are the same providers you connect from **Settings → Integrations** in the dashboard.

  Please [read this page](/docs/providers) for more information about all current supported providers.

POST /providers

DELETE /providers/:provider_key_name

## Remove a provider API (api-reference/providers/remove)

DELETE /providers/{provider_key_name}
Delete a previously added provider from your Bolna account, ensuring your integrations remain current.
