# Packet: Ep 7 The Agent Builder Explained Tab by Tab

## Configure multilingual agent prompts and hangup settings (agent-setup/agent-tab)

Set up your Bolna Voice AI agent's welcome message, per-language prompts with dynamic variables, language switching, and call hangup conditions.

The Agent Tab controls your agent's welcome message, prompts, and conversation behavior. Add multiple languages, set a default, and write a dedicated prompt for each.

## Agent welcome message

The first thing callers hear when they connect.

**Keep it short**:
    Brief greetings work best. Long announcements feel robotic.

**Use variables**:
    Personalize with `{{variable_name}}`, e.g. `{{customer_name}}`.

### Welcome message behavior

| Setting | What it controls |
| - | - |
| **Ignore user speech before welcome message** | Discards speech received before the welcome message finishes playing. |
| **Welcome Message Delay (in ms)** | Waits `0–1000` milliseconds before the agent starts the welcome message. |

## Canvas

  This section covers the canvas where each language has its own prompt. New agents in accounts with the **Single Prompt view (Beta)** use one shared prompt for all languages instead. See [Single Prompt view](/docs/agent-setup/single-prompt-view) to check which view your agent uses.

Each language gets its own prompt. Select a language tab and write the prompt for that language. The agent activates the matching prompt when speaking in that language during a call.

### Managing languages

Languages are **added and removed here**, in the Agent Tab. The [Languages Tab](/docs/agent-setup/audio-tab) shows the same set of languages and is where each one gets its own [voice and transcription providers](/docs/agent-setup/audio-tab).

**Add a Language**:
    Click **+ Add Language** to create a new language tab.

**Set the Default**:
    Click the **crown icon** next to any language to make it the default. The default language is what the agent starts every conversation in, marked with **(Default)** in the tab.

**Write Per-Language Prompts**:
    Select each language tab and write its prompt in that language's **native script** — see [Non-English Prompts](/docs/writing-prompts-in-non-english-languages) for guidelines. Don't include language-switching instructions in it; switching is automatic — see [How Language Switching Works](/docs/customizations/language-switching-behavior).

**Remove a Language**:
    Click the **x** on a tab to remove it. The default language cannot be removed — promote another language first.

### Prompt structure

**Recommended Prompt Sections**:
  | Section | Purpose | Example |
  | - | - | - |
  | **Personality** | Tone and feel | "warm, perceptive, and results-driven" |
  | **Context** | Role background | "You are calling on behalf of Acme Corp..." |
  | **Instructions** | Tasks and flow | "Ask for their order number first..." |
  | **Guardrails** | Restrictions | "Never discuss competitor products..." |

The editor shows a **token count** in the bottom-right to help you stay within LLM limits.

### Variable syntax

| Syntax | Purpose | How to use |
| - | - | - |
| `{{variable_name}}` | Insert or define variables | Type `{` to open the variable picker. Select an existing variable or type a new name to create one. |
| `{variable_name}` | The same variable, single-brace form | Still accepted, e.g. for prompts carried over from an earlier agent. The editor keeps whichever form you typed. |
| `{variable.path}` | Read into a variable that holds a JSON value | Dot and bracket notation both work — `{prior.score}`, `{prior[loans][0][amount]}`. Only the root (`prior`) is a variable you fill in. See [Adding Variables](/docs/prompting/using-context#reading-into-a-json-value). |
| `@` | Insert prompt modules, custom functions, or variables | Type `@` to browse and select existing modules, functions, or variables. You cannot create new items with `@`. |

**Variables with {{ }}**:
    Select existing variables or **create new ones** by typing a name. Values are passed via API or CSV at call time.

**Modules and functions with @**:
    Select existing [prompt modules](/docs/prompting/introduction#prompt-modules), [custom functions](/docs/tool-calling/custom-function-calls), or variables. Cannot create new items.

### Browse modules

Click the **Browse Modules** button in the top-right of the prompt section to open the full modules library. Browse by category (Collection, Optional, Flow, Sector, Universal), preview what each module does, and insert it directly into your prompt. See the [Prompting Guide](/docs/prompting/introduction#prompt-modules) for the full list of available modules.

### AI edit

Click **AI Edit** in the top-right of the prompt section to open a chat panel and rewrite the prompt by describing the change you want. The rest of the Agent Tab steps aside while the panel is open, so the prompt gets the full height of the screen.

  AI Edit is in **beta** and is free to use during the beta.

**Ask for a Change**:
    Describe the change in the composer, e.g. "ask for the order number before anything else" or "make the tone warmer and cut the closing script down". Each message is answered against whatever the prompt says at that moment, so you can keep editing in the Canvas between messages.

**Review the Proposed Changes**:
    A rewrite comes back as a diff — added lines in green, removed lines in red. Click the expand icon on the **Proposed changes** card to read a long rewrite at full height.

**Approve or Discard**:
    **Approve edit** writes the rewrite into the Canvas and saves the prompt. **Discard** leaves the prompt untouched. Every proposal has to be approved or discarded before you can send the next message.

The session works on **one language's prompt**. The language you had selected when you opened the panel is shown as a read-only label, and languages cannot be switched or added until you close the panel. Reopening the panel for the same agent and language picks the conversation back up.

  Approving an edit saves the prompt, but not the agent. Click **Save agent** for the new prompt to be used on calls.

### Revert AI edit change

While the panel is open, **Revert AI Edit change** in the top-right puts the prompt back to how it was before the editing session started. It becomes available once you have approved at least one edit, and asks for confirmation because everything you approved during the session is discarded.

  The revert point only lasts as long as the session — closing the AI Edit panel discards it. Approved edits are already saved at that point and stay in the prompt.

## Per-language hand-in settings

**Agent name** and **Hand-in message** — both optional — are set per language in the [Languages Tab](/docs/agent-setup/audio-tab#hand-in): how the agent introduces itself in a language and what it says while switching into it.

## Prompt variables for testing

When you use `{{variable_name}}` in your prompt, those variables **automatically appear** as input fields in the testing section. Fill in test values to preview how the prompt behaves before going live.

The **Timezone** selector (e.g., `Asia/Kolkata UTC+05:30`) is a separate field that sets the timezone context for test calls.

#### JSON Variables

A variable the prompt reads into with a path `{prior.score}` holds a whole JSON value rather than a single word, so it is listed separately under **JSON variables** below the one-line fields. Each one gets a taller JSON editor with syntax highlighting, an error marker on the offending character, and a **Format** button that re-indents the value. A value that is not valid JSON yet is flagged, because path references cannot resolve against it.

## Hangup using prompt

Let your agent decide when to end calls based on conversation context instead of silence detection or timeouts.

**Enable the Toggle**:
    Turn on **Hangup using a prompt**.

**Define Completion Conditions**:
    Write conditions for when a conversation is complete. For multilingual agents, include closing lines in each language.

**Example: Multilingual Hangup Prompt**:
  ```
  A conversation is considered complete if any of the following conditions are met:
  User is not interested:
  The assistant has said the following closing line:
    Conversation Closing (English): "That is sad to hear. But no worries if you would ever want to learn more give me a cool."
    Conversation Closing (Hindi): "ये सुनकर अफ़सोस हुआ। लेकिन कोई बात नहीं, अगर आप कभी और जानना चाहें तो मुझे call कर लें।"
  The user has responded after that with any of the following phrases: "goodbye", "bye", "thank you", "thanks", "ok", "okay", or similar.
  The last message in the transcript must be from the user.
  ```

  Without this, calls end only on silence detection or timeouts.

## Configure languages, voice and transcription settings (agent-setup/audio-tab)

Set up languages, voice, and transcription for your Bolna Voice AI agent. Pick providers, select voices, clone custom voices, and tune audio quality.

The **Languages** tab (previously labeled **Audio**) controls how your agent listens and speaks. Pick the language you are configuring, then set its voice and transcription providers and tune audio quality. For multilingual agents, you can select **different transcription and voice providers and hand-in messages per language**.

## Languages

The strip at the top of the tab, labeled **Settings for**, selects which language the voice and transcription settings below apply to. The language marked `(Default)` is the one your agent opens every conversation in.

  Languages are **added, removed, and promoted to default** in the [Agent Tab](/docs/agent-setup/agent-tab). On this tab the strip only switches between the languages you already configured there.

### When the agent switches language

For multilingual agents, a summary under the strip recaps the setup — for example "Starts in **English**, can move to **Hindi**, **Dutch** when ..." — and ends in a dropdown that controls when a switch is allowed: **requested or auto detected** (the default) or **the caller requested for it**. See [When the Agent May Switch](/docs/customizations/multilingual-languages-support#when-the-agent-may-switch) for what each option means, and [How Language Switching Works](/docs/customizations/language-switching-behavior) for exactly what counts as "the caller speaking another language" — why a stray English word or a read-out order number won't trip a switch.

### Supported languages

See the [Supported languages](/docs/customizations/supported-languages) page for the full list of languages Bolna can be configured with.

## Voice

Controls how your agent sounds when speaking to the caller. For multilingual agents, each language can have its own voice provider, model, and voice. Select a language in the strip above to configure its voice settings independently.

### Provider, model, and voice

**Select a Provider**:
    Choose from **AzureTTS**, **Cartesia**, **ElevenLabs**, or **Sarvam**.

**Pick a Model**:
    Select the model that fits your latency and quality needs (e.g., ElevenLabs `eleven_turbo_v2_5` for low latency).

**Choose a Voice**:
    Click the **Voice** dropdown to browse all voices for the selected provider and model.

### Browsing voices

Click the Voice dropdown to see a searchable list of all available voices. Filter by gender using the **All**, **Male**, **Female**, and **Neutral** tabs. Each voice shows a **play button** so you can preview it before selecting.

### Preview welcome message

Click the **play button** next to the Voice dropdown to hear the selected voice speak your agent's welcome prompt (configured in the [Agent Tab](/docs/agent-setup/agent-tab)). This lets you test how the voice sounds before going live.

### Voice tuning parameters

Fine-tune your agent's voice using the sliders under **Advanced settings**, below the voice selector. Available parameters may vary by provider.

| Parameter | What it controls |
| - | - |
| **Buffer Size** | Audio buffered before playback begins. Higher values produce smoother audio but increase delay. Values between 150 and 250 work well for real-time conversations. |
| **Speed Rate** | Speaking speed. `1` is natural pace, above `1` is faster, below `1` is slower. |
| **Similarity Boost** | How closely the output matches the original voice sample. Higher values are more faithful but may reduce naturalness. |
| **Stability** | Voice consistency across sentences. Higher values keep tone steady, lower values add expressive variation. |
| **Style Exaggeration** | Emphasis on stylistic characteristics. `0` is neutral, higher values add more personality. |

  High **Buffer Size** improves quality but adds latency. If callers notice a delay before the agent speaks, lower this value.

## Adding and cloning voices

Open the **Voice** dropdown and click **Add new voice** at the bottom to add a custom voice by ID or clone one from an audio sample. This opens the **Add Voice** dialog.

  Custom voice uploads are **only available for ElevenLabs and Cartesia**.

### Add a voice by ID

Use this when you already have a voice ID from your provider's voice library.

**Select the Add by ID tab**:
    Make sure the **Add by ID** tab is selected in the dialog.

**Choose a Provider**:
    Select **ElevenLabs** or **Cartesia**.

**Enter the Voice ID**:
    Paste the voice ID from your provider. For ElevenLabs, find IDs in the [ElevenLabs voice library](https://elevenlabs.io/voice-library).

**Click Add voice**:
    The voice will appear in the Voice dropdown for all your agents.

### Clone a voice

Create a new voice by uploading an audio recording. Useful for maintaining a consistent brand voice or using a specific person's voice (with their permission).

**Select the Clone Voice tab**:
    Switch to the **Clone Voice** tab in the dialog.

**Choose a Provider**:
    Select **ElevenLabs** or **Cartesia**.

**Enter Voice Details**:
    Add a **Voice name** (e.g., "Sales Assistant Voice") and **Description** (e.g., "Warm male Indian accent").

**Select Sample Language**:
    Choose the language of your audio sample.

**Upload an Audio Sample**:
    Drag and drop your audio file or click **click to browse**. Audio files only, maximum 10 MB.

**Click Clone voice**:
    The platform processes your sample and adds the new voice to the Voice dropdown.

### Supported languages for voice cloning

Both ElevenLabs and Cartesia support cloning in the same [languages Bolna supports](/docs/customizations/supported-languages), plus an additional **Indian Multilingual** sample-language option.

  For best results, use a clean recording with no background noise, a single speaker, and at least 30 seconds of continuous speech.

## Transcription

Controls how your agent converts the caller's spoken words into text before the LLM processes them. For multilingual agents, each language can have its own transcription provider and model. Select a language in the strip above to configure its transcription settings independently.

  Different languages may perform better with different providers — see [Per-Language Configuration](/docs/customizations/multilingual-languages-support#per-language-configuration) for a worked example.

### Provider and model

Choose a transcription provider from the **Provider** dropdown, then pick the specific model from the **Model** dropdown.

| Provider | What it offers |
| - | - |
| **Deepgram** | High-accuracy, low-latency transcription; reads the Keywords field |
| **Deepgram Flux** | Turn detection built into the model — lowest latency and the most accurate barge-in |
| **AssemblyAI** | Universal-3.6 Pro: 32 languages with code-switching, strong on short answers and noisy lines |
| **Azure** | Microsoft Azure Speech Services |
| **ElevenLabs** | Scribe realtime; also reads the Keywords field (first 50 terms) |
| **Gemini** | Google Gemini streaming speech-to-text |
| **Gladia** | Multilingual transcription with code-switching |
| **Google** | Google Cloud Speech-to-Text |
| **OpenAI** | GPT Realtime transcription with built-in VAD |
| **Sarvam** | Optimized for Indian languages like Hindi, Tamil, and Telugu |
| **Smallest** | Lightweight, fast transcription provider |
| **Soniox** | Multilingual with native mid-sentence code-switching |

### Keywords

Boost recognition accuracy for specific words the transcriber might miss, such as brand names, product names, or technical terms. Enter one term per entry, comma-separated (e.g., `Bruce, Acme, Meesho`).

  Not every transcriber reads this field,When your
  selected transcriber or model can't use it, the box is shown disabled. See
  [provider support](/docs/customizations/asr-keywords-and-context#provider-support) for which providers
  read it and their limits.

  The boost value is not passed through to the transcriber. Deepgram receives the terms as `keyterm` on
  `nova-3` and Flux and as `keywords` on `nova-2` and earlier; ElevenLabs receives them as keyterms.
  None of those carry weights, and agents created through the
  [Create Agent API](/docs/api-reference/agent/v2/create) have the `:boost` suffix stripped before storage.
  Enter plain terms — `Bruce` rather than `Bruce:100`.

### Advanced settings

Some transcribers have settings of their own, under **Advanced settings** below the Keywords and Context fields. The section is collapsed by default and only appears for a provider that has such settings.

| Provider | Settings |
| - | - |
| **AssemblyAI** | **Mode**, **VAD threshold** and **Longest pause in a turn**. Mode applies to the Universal-3 models only |
| **Deepgram Flux** | **EndOfTurn Threshold**, **EndOfTurn Timeout** and **Eager EndOfTurn** |
| **OpenAI** | **Transcription Delay** and **Noise Reduction** |

Each AssemblyAI setting opens on the value AssemblyAI uses when you leave it alone, so you can see what you are changing from. Raise **Longest pause in a turn** if callers get cut off while reading out numbers or addresses, and raise **VAD threshold** if line noise interrupts the agent. See [AssemblyAI session settings](/docs/assemblyai#session-settings) for what each does and the settings available over the API.

## Hand-in

Shown only when the agent has more than one language. These two fields cover how the agent moves **into** the language selected in the strip above.

| Field | Description |
| - | - |
| **Agent name** | How the agent introduces itself while switching to this language, e.g. `Maya`. |
| **Hand-in message** | What the agent says while transitioning into this language, for example `Connecting you to Maya, who speaks Hindi.` |

  Both are **optional** — leave them blank and the agent switches without a spoken hand-in line. These fields used to live under **Advanced Settings** in the Agent Tab, where they were called Agent Name and Handoff Message. They are still per language — the values set for Hindi do not affect English.

## Configure telephony, noise, and call timing for voice AI (agent-setup/call-tab)

Set up telephony providers like Plivo and Twilio, plus noise cancellation, voicemail detection, DTMF input, inbound calling, and outbound calling-hour restrictions.

## What is the Calling tab?

The Calling Tab is where you configure how your agent handles phone calls. Set up your telephony provider, enable call features like noise cancellation and voicemail detection, turn on **Inbound Calling** for this agent, and restrict outbound calling hours.

  Final call message and hangup timers moved to the [Engine Tab](/docs/agent-setup/engine-tab#final-call-message-%26-call-management).

## Configuration options

### Telephony provider & call features

Configure your telephony provider and toggle powerful call capabilities.

**Noise cancellation**:
    Filter background noise for clearer calls (adjustable intensity)

**Voicemail detection**:
    Detect voicemail systems to avoid awkward messages

**Keypad input (DTMF)**:
    Accept touch-tone input for IVR-style menus

**Auto reschedule**:
    Automatically retry failed calls later

  Connect your own telephony provider in [Settings → Integrations](/docs/providers) for more control and cost savings.

### Ambient noise

Add background ambient noise to your calls for a more natural, human-like experience. Ambient noise is available for **Plivo** and **Vobiz** telephony providers.

Bolna supports both **preset** and **custom** ambient noise tracks. Select a preset or upload your own custom track to use as background noise during calls.

#### Preset Tracks

Three preset tracks are available to all users out of the box:

| Track | Description |
| - | - |
| **office-ambience** | Subtle office background noise |
| **call-center** | Call center ambient sounds |
| **coffee-shop** | Background sounds of a coffee shop environment |

Set ambient noise to **None** to disable it (default).

#### Custom Tracks

Use the **+** button next to the dropdown to upload your own ambient noise track, and the play button to preview the selected track:

* **Supported formats**: `wav`, `mp3`
* **Maximum file size**: 10 MB
* You can upload, list, and delete your custom tracks from the dashboard or via the API
* Custom tracks are private to your account, while presets are available to everyone

  Ambient noise is only supported with **Plivo** and **Vobiz** telephony providers.

### Inbound calling

Inbound settings live inside the Calling tab. Toggle on **Inbound Calling** to assign an inbound number to this agent, match callers against a database, and set spam limits.

| Setting | Description |
| - | - |
| **Inbound number** | Pick one of your [phone numbers](/docs/buying-phone-numbers) to route incoming calls to this agent |
| **Database for inbound phone numbers** | Match callers to a CSV, Google Sheet or API and preload their data |
| **Spam Prevention Settings** | Cap calls per phone number and maintain an always-allow list |

  The full walkthrough is in [Inbound Calling settings](/docs/agent-setup/inbound-tab).

### Outbound call timing restrictions

Restrict outbound calls to a specific time window. This is **off by default**. Toggle it on to set an allowed calling window.

| Field | Description |
| - | - |
| **Allowed Time Window** | Set a start and end time (e.g., 9:00 AM to 9:00 PM). Calls outside this window are automatically rescheduled to the next allowed time. |

The time window is validated against the **recipient's local timezone**, detected automatically from their phone number. For example, a 9 AM start means 9 AM in the recipient's timezone, not yours.

  Many regions have laws restricting when you can make outbound calls. Enable timing restrictions to stay compliant with local regulations.

  You can also configure call timing restrictions via the API and bypass them for urgent calls. See the full [Calling Guardrails](/docs/outbound/calling-guardrails) guide for details.

## Which prompt view the imported agent uses

If the [Single Prompt view (Beta)](/docs/agent-setup/single-prompt-view) is enabled for your account, the imported copy opens in it when the source agent has **one language**, or when the source agent already uses the Single Prompt view. If the Single Prompt view isn't enabled for your account, imported agents open in the older canvas.

## Choose and configure LLM models for voice AI (agent-setup/llm-tab)

Select and configure the language model for your Bolna Voice AI agent. Choose from OpenAI, Azure, Anthropic, and connect knowledge bases.

## What is the Intelligence tab?

The **Intelligence** tab (previously labeled **LLM**) is where you select and configure the intelligence behind your voice AI agent. Choose your language model provider, adjust response parameters, and connect knowledge bases for enhanced conversations.

## Configuration options

### Choose LLM model

Select your AI provider and model for conversation intelligence.

**Provider selection**:
    Choose from Azure, OpenAI, Anthropic, Groq, and more

**Model selection**:
    Pick the specific model (e.g., `gpt-4.1-mini`)

  Connect your own provider keys in [Settings → Integrations](/docs/providers) to reduce costs and access more models.

### Model parameters

Fine-tune how your agent generates responses.

| Parameter | Description | Recommended |
| - | - | - |
| **Tokens generated on each LLM output** | Maximum tokens per LLM output | 300-500 for concise responses |
| **Temperature** | Controls creativity/randomness | 0.3-0.5 for balanced responses |
| **Verbosity** | Controls how detailed the visible answer is. Appears only for supported reasoning models | Low for concise voice responses |
| **Reasoning effort** | How much the model reasons before answering. Shown for models that support it | Lowest available setting for voice |

  **Keep temperature low** (0.3-0.5) if you want consistent, controlled responses. Higher temperature increases creativity but may cause deviation from your prompt instructions.

  GPT-5 models are the exception: they accept only `1`, so the temperature control has no effect on them. Constrain those agents through the prompt instead.

  On GPT-5 models, reasoning tokens are drawn from the same budget as **Tokens generated on each LLM output**, so raise the cap whenever you raise reasoning effort. The effort control lists only the values the selected model accepts, and the options change when you switch models. See [OpenAI](/docs/openai-llm#reasoning-effort) for the per-model values.

#### Extra request params

With a [custom model](/docs/custom) selected, the tab also shows **Extra request params**. Switch it on to send your server parameters beyond the OpenAI standard as JSON, for example `{"chat_template_kwargs": {"enable_thinking": false}}` to turn Qwen3's thinking off on vLLM. The example buttons fill in common ones. See [Extra request params](/docs/custom#extra-request-params).

### Add knowledge base

Connect your knowledge bases to give your agent accurate, contextual information.

**Click the Dropdown**:
    Open the **"Select knowledge bases"** multi-select dropdown.

**Select Knowledge Bases**:
    Check one or more knowledge bases (PDFs, URLs) to connect.

**Create New (Optional)**:
    Click **"Add new knowledgebase"** to create and upload new content.

  Knowledge bases enable your agent to answer questions with accurate, up-to-date information from your documents and URLs. Connect multiple knowledge bases for comprehensive coverage.

  Create knowledge bases in the [Knowledge Base](/docs/knowledge-base) section by uploading PDFs or adding URLs.

## Configure voice AI agents in Bolna (agent-setup/overview)

Complete guide to configuring Bolna Voice AI agents. Customize prompts, test conversations, and deploy agents for inbound and outbound calls.

## Open Agent Studio

Agent Studio is where you configure and fine-tune your Voice AI agents. Open **Build → Agent Studio** in the [Bolna Platform](https://platform.bolna.ai/dashboard) sidebar, then create or select an agent.

To generate a complete agent from a short description instead of configuring each tab yourself, use [Auto Build](/docs/agent-setup/studio).

## Your agents sidebar

The left sidebar shows all your agents and provides quick access to create or import agents.

| Action | Description |
| - | - |
| **New Agent** | Create an agent using **Auto Build**, **Start from Template**, or from scratch |
| **Import** | Import an existing agent configuration using an [agent ID](/docs/agent-setup/copy-import-agent) |
| **Search** | Quickly find agents by name |
| **Agent List** | Click any agent to open its configuration; use the **⋮** menu to Rename, Share, Duplicate or Delete |

  New agents are created in **draft** status until you save them.

## Agent header

The header bar displays key information and quick actions for your selected agent.

| Element | Description |
| - | - |
| **Agent Name** | Your agent's display name — click to edit inline |
| **Voice engine** | Switch between **Cascaded** (separate transcriber, LLM and voice) and other engines |
| **Copy Agent ID** | Copy the agent ID for API integrations |
| **Call history** | Jump to this agent's [call history](/docs/agent-setup/call-history) |
| **Cost per min** | Estimated cost breakdown per minute (Agent Cost, Telephony, Platform), with a **Preferred Price** badge when the agent uses [preferred models](/docs/pricing/preferred-models) |
| **Routing** | Active routing region (e.g., India routing) |

  Inbound number assignment now lives inside the **Calling** tab under **Inbound Calling** — see the [Inbound Calling settings](/docs/agent-setup/inbound-tab).

## Testing & saving

Test your agent before deploying and save your changes. All actions sit in the bottom-right action bar of the editor: **Save agent**, **Get a call from agent**, and a dropdown arrow that opens the other test options.

### Testing options

## Single Prompt view for multilingual agents (agent-setup/single-prompt-view)

Write one prompt for every language your Bolna agent speaks: mark the lines that need translating and review each language's wording in the Translations panel.

Build a multilingual agent from one prompt instead of maintaining a separate prompt for every language. You write the role, rules and call flow once, then mark only the lines the agent speaks out loud. Bolna gives each marked line its own wording per language; everything else is shared.

  **Beta.** The Single Prompt view is being A/B tested, so it may not be on your account yet. To turn it on, email [support@bolna.ai](mailto:support@bolna.ai).

## Why one prompt

A multilingual agent is really one conversation spoken in several languages. The Single Prompt view treats it that way.

* **Change it once, everywhere.** Rules, call flow and instructions live in one shared prompt. Edit them once and the change applies to every language, with no tabs to hop between and no edits to repeat.
* **Your languages never drift apart.** With a single source, there's no risk of updating Hindi and forgetting Tamil. Every language runs the same logic.
* **No translating by hand.** Mark the lines your agent speaks and Bolna translates them into each of your languages. You only step in to review or fine-tune the wording.

In the [older canvas](/docs/agent-setup/agent-tab#canvas), each language has its own full prompt, even though most of that text is identical. Every change has to be repeated in each tab, and over time the tabs fall out of sync.

Here's how the two compare:

| | Older canvas | Single Prompt view |
| - | - | - |
| **Prompts** | One full prompt per language | One prompt for all languages |
| **What differs by language** | Everything in that tab | Only the lines you mark |
| **Changing a rule** | Edit every language tab | Edit once |
| **Adding a language to a saved agent** | A blank tab to write by hand | Marked lines are translated automatically |

## Which agents use the Single Prompt view

An agent's view is set when it's created and saved with it. Enabling the view on your account doesn't change agents you already have; they keep working exactly as before, in the editor and on calls.

The table assumes the Single Prompt view is enabled for your account.

| Agent | Opens in |
| - | - |
| **New agent** created in Agent Studio | Single Prompt view |
| **Imported agent** with one language | Single Prompt view |
| **Imported agent** already using the Single Prompt view | Single Prompt view, whatever its number of languages |
| **Imported agent** with more than one language | Older canvas |
| **Existing agent** created before you had the view | Older canvas |

Imported multi-language agents stay on the older canvas because their separate per-language prompts don't map onto one shared prompt. See [Import agents](/docs/agent-setup/copy-import-agent).

  **How to tell which view you're in:** the Single Prompt view shows language chips with a **+** icon. The older canvas shows language tabs with a **+ Add Language** button.

## How translation works

Every line in the prompt is either **marked** or **unmarked**.

* **Marked lines** have their own wording in each language. On a call, the agent uses the wording for the caller's language. Mark what the agent says out loud: the opening line, questions, confirmations and closing lines.
* **Unmarked lines** stay exactly as written, in every language. Instructions, rules and section headings usually stay unmarked.

You write the prompt in your **default language**, shown with a crown. Every other language takes its wording from it.

  If an agent has more than one language and no lines are marked, the Canvas shows a warning. Without marked lines, the agent speaks every line in the default language on all calls.

### Mark a line for translation

**Hover over the line**:
    A translate icon appears in the left margin, with the tooltip **Mark as translation to auto-translate across all current and future languages**.

**Click the icon**:
    The line turns blue and the **Translations** panel opens for it.

### Mark a phrase within a line

To translate only part of a line, such as the question after a label or the example replies inside an instruction, mark just those words.

**Select the words**:
    Highlight the phrase in the prompt. A **Mark for translation** button appears.

**Click Mark for translation**:
    The phrase turns blue. The rest of the line stays shared text.

### Change or unmark a marked line

To change a marked line later, click it and choose:

* **View translations** to open the Translations panel.
* **Unmark** to turn it back into shared text. You can also click the translate icon again.

### Edit a line's wording

The **Translations** panel opens on the right of the Canvas. It shows one box per language for the selected line. The language you're viewing is labelled **Viewing**, and your default language is labelled **Default**.

**Edit the wording**:
    Type or correct the wording in any language's box.

**Click Save**:
    **Save** stays disabled until you change something. To drop your changes, click **Discard** (or **Cancel** on a line you've just marked).

**Click Save agent**:
    The panel only saves wording into the Canvas; the agent isn't saved until you do this.

If the agent has only one language, the panel tells you to add another before you can translate the line.

## Manage languages

Languages appear as chips at the top of the Canvas. The default language has a crown, and the eye icon shows the one you're viewing. Click a chip to see the prompt in that language. Voice and transcription for each language are still set in the [Languages Tab](/docs/agent-setup/audio-tab).

### Add a language

Click the **+** icon and pick a language from **Available languages**. What happens next depends on the agent:

| Agent state | What happens |
| - | - |
| **Saved, with marked lines** | Bolna translates every marked line. A notification reads **Adding \** and changes to **\ added** when done, usually within a minute. If no wording comes back, the language is still added and you'll see **Translations are not ready**; fill in the wording from the Translations panel. |
| **No lines marked** | A dialog asks you to choose **Mark lines first** or **Add language anyway**. |

Marked lines that still have no wording in a language are highlighted, that language's chip shows an amber dot, and a banner tells you how many lines need wording.

### Change the default language

Open the language picker, hover over a language under **Selected languages** and click **Make default**.

### Remove a language

In the same picker, hover over the language and click the remove icon. Removing a language deletes its wording for every marked line, along with its voice, speech recognition, handoff and related settings. You can't remove the default language; make another language the default first.

## Work with sections

The prompt is split into collapsible sections. A new agent built from scratch starts with **Identity and Demeanour**, **Conversation Starter**, **Conversation Flow**, **Closing**, and **Frequently Asked Questions**. Each has placeholder text to replace with your own.

* **Collapse or expand** a section with the chevron next to its heading.
* **Add a section** with **+ Add Section** at the bottom of the Canvas, or type `#` in the prompt.
* **Delete a section** with the delete icon on its heading. This removes the heading and everything under it.
* **Go full screen** with the expand icon at the top right of the Canvas.

Variables (`{{`), modules (`@`), **Browse Modules** and the token count work as described in the [Agent Tab](/docs/agent-setup/agent-tab).

## Use AI Edit

[AI Edit](/docs/agent-setup/agent-tab#ai-edit) works on the shared prompt, so its changes apply to every language. When it edits a marked line, the suggestion can include that line's wording in your other languages.

While AI Edit is open, you can switch the language you're viewing, but you can't add or remove languages or change the default.
