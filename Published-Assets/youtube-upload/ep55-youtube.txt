TITLE
Self-Host Bolna Open Source With Docker: Twilio or Plivo Calls Locally

DESCRIPTION
Bolna open source ships a Docker setup in local_setup: a telephony server (Twilio or Plivo), the Bolna server, ngrok and Redis. This documented walkthrough covers what each container does and which port it uses, filling .env from .env.sample, the ngrok authtoken, the start.sh quick start, the manual docker compose route, running only the telephony server you need, what the compose file mounts, how an agent is created before a call, and a checklist for a local setup that never calls.

This episode is a documented walkthrough built from the official Bolna documentation (links below). It does not include a live product recording. Narration uses a synthetic text-to-speech voice; visuals are motion graphics built from the docs, not screen recordings of the Bolna dashboard.
