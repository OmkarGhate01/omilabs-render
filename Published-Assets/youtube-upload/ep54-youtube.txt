TITLE
Bolna Open Source Explained: Self-Hosted Voice AI Agents (MIT)

DESCRIPTION
Bolna open source is the orchestration engine behind Bolna's voice agents, released on GitHub under the MIT license. This episode is a documented walkthrough of the repo's README: what is open (the orchestration platform) and what is not (the hosted APIs and no-code playground), how a conversation flows from telephony through transcriber, LLM and synthesizer over websockets, every supported provider, the .env keys you bring yourself, how to add a telephony or TTS provider, and when self hosting actually makes sense.

This episode is a documented walkthrough built from the official Bolna documentation (links below). It does not include a live product recording. Narration uses a synthetic text-to-speech voice; visuals are motion graphics built from the docs, not screen recordings of the Bolna dashboard.
