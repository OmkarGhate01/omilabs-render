TITLE
Bolna Open Source in Python: Agents, Examples and the Agent API

DESCRIPTION
Bolna open source has no dashboard, so you build agents in Python or as JSON. This documented walkthrough covers the repo's simple_assistant.py example (Deepgram, OpenAI and ElevenLabs in one streaming pipeline), the text-only example, the keys each one needs, the agent JSON from API.md (toolchain, tools_config, task_config, prompts), the five agent API endpoints, and the quickstart client that talks to an agent from your microphone over a websocket.

This episode is a documented walkthrough built from the official Bolna documentation (links below). It does not include a live product recording. Narration uses a synthetic text-to-speech voice; visuals are motion graphics built from the docs, not screen recordings of the Bolna dashboard.
